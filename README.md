# End-to-End Brewery Data Pipeline

ETL pipeline and analysis for **Case A** of the [Basic End-to-End Pipeline Design](./End-to-End%20Pipeline%20Design.pdf) task: fetch brewery data from the [Open Brewery DB API](https://www.openbrewerydb.org/), load it into a local SQLite database, answer analytical questions, and produce visualizations.

Two entry points for the same pipeline:

- `[End-To-End-Pipeline.ipynb](./End-To-End-Pipeline.ipynb)` — preferred for reading: interactive walkthrough with exploration, `/meta` cross-checks, and inline charts
- `[pipeline.py](./pipeline.py)` — same ETL, answers, and charts as a single runnable script (prints to the terminal, writes charts to `out/`)



## Pipeline


| Stage         | Function             | What happens                                                                                       |
| ------------- | -------------------- | -------------------------------------------------------------------------------------------------- |
| **Extract**   | `extract()`          | Paginated `GET` requests to `https://api.openbrewerydb.org/v1/breweries` (200 records per page).   |
| **Transform** | `filter_data()`      | Keep relevant columns: `id`, `name`, `brewery_type`, `state_province`, `country`, `city`, `phone`. |
| **Load**      | `save_local_db()`    | Write the cleaned table into SQLite (`brewery.sql`, table `brewery`).                              |
| **Answer**    | `answer_questions()` | Run analytical SQL queries and print answers to the four case questions.                           |
| **Visualize** | `visualize()`        | Build charts from aggregated SQL results and save them under `out/`.                               |


Analysis and charts are run against the database with SQL + pandas, not against raw API dumps. Some answers are cross-checked with the API `/meta` endpoint in the notebook.

## Answers


| #   | Question                                       | Result                                                                                                                                     |
| --- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Which US state has the most microbreweries?    | **California** (466)                                                                                                                       |
| 2   | Top 5 US states by microbreweries?             | California, Washington, Colorado, New York, Texas                                                                                          |
| 3   | How many brewpubs in Incheon, South Korea?     | **2**                                                                                                                                      |
| 4   | (Bonus) Phone number patterns by city in Korea | Shared prefixes per city (e.g. Andong-si → `054-`, Gangneung-si → `033-`, Seogwipo-si → `064-`), matching Korean area-code style numbering |


Counts reflect a full API pull (~11,959 breweries at run time) and may change if the upstream data changes.

## Visualizations

Charts are generated by `visualize()` from aggregated SQL results and saved under `out/`:

1. **Bar chart** — top 5 US states by microbrewery count (`out/top_five_us.png`)
2. **Choropleth map** — breweries per US state (`out/breweries_per_state.png`)

The notebook also produces a **pie chart** of brewery type distribution (`out/brewery_types.png`).

## How to run

```bash
pip install -r requirements.txt
python pipeline.py
```

Or open `[End-To-End-Pipeline.ipynb](./End-To-End-Pipeline.ipynb)` and run all cells.

Both write SQLite (`brewery.sql`) and charts under `out/`. No external database server is required.
